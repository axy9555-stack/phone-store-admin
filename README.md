# 手机店销售管理系统

一个给线下手机店用的单页销售管理系统：纯静态网页（原生 JS，无框架、无 CDN），中文界面，手机优先；数据全部存在本机浏览器 localStorage，离线也能用。发布到 GitHub Pages / Altare 等任意静态托管即可使用。

## 功能清单

- **看板（默认首页）**：今日销售额 / 订单数 / 毛利 / 库存总值四个数字卡片、畅销榜 Top5、低库存预警（点击跳库存页）、近 6 个月销售额柱状图（纯 CSS）、最近 10 笔订单。
- **收银（POS）**：商品搜索加购；手机逐台占串号（加购冻结为"已锁定"防重卖，结账才真正出库）；整单立减 / 打折（折后不得低于成本）；以旧换新估价抵扣；现金（自动找零）/ 微信 / 支付宝 / 刷卡 / 储值（扣会员余额）五种支付；结账生成小票样式的成功页，可打印（window.print）。
- **库存**：商品搜索 / 分类筛选；新增商品（售价须高于进价，手机须走采购入库）；调价并留调价记录；库存总值、低库存预警；点商品展开串号（IMEI）列表。
- **采购**：新建采购单（多行商品、自动带进价、自动合计）；收货入库——配件按数量、手机逐台录 15 位串号（查重、防错录）；待收货单可收货、可取消。
- **订单**：订单列表（按日期 / 店员 / 支付方式 / 关键词筛选）；订单详情；整单或部分退货（手机串号回库、配件回库，退款按原价，状态改已退货 / 部分退货，写退货记录）；以旧换新估价工具。
- **店员**：店员增改（手机号 11 位且唯一）、角色管理（只有店长能授店长）、考勤打卡（出勤 / 请假 / 迟到，同日覆盖）、按月销售额与订单数查询。
- **提成**：规则可改（手机 2% / 配件 5% / 维修 10% / 换新回收 1%，比例限 0–30%）；阶梯加成按超出部分边际计算（满 10 万 +0.5%、满 20 万 +1%）；逐单提成明细；月度结算单（结算后锁定快照不再重算）；全店提成榜。
- **会员**：会员增改（手机号唯一）、储值充值（只加不减，写流水）/ 储值消费、积分 1 元 = 1 分（收银结账自动累计，支持手工调分）、等级按累计消费自动升级（满 5000 银卡、满 20000 金卡）、消费记录与流水查询。
- **国补**：国家以旧换新消费品补贴——手机单件售价 ≤6000 元可补 15%（单件最高 500 元），每人每类限 1 件（按身份证号）；收银页可直接为购物车手机申请国补（校验资格、应付立减、与优惠 / 换新叠加）；结账自动生成国补记录，商家垫付后走 待申报 → 已申报 → 已到账（或驳回后可重新申请）流程；待结算总额汇总，规则可改。
- **维修售后**：维修接单（必填客户电话与故障，可挂串号占机）；状态按 待检修 → 维修中 → 待取机 →（结算完工）已完成 流转，不能跳级，可取消（串号归位）；完工写一笔维修收入订单并入维修员提成；保修查询——售出起 1 年保修，每修一次延保 90 天，显示剩余天数。
- **设置**：数据备份导出（下载 .json）、导入备份（校验顶层 key 齐全，覆盖前弹窗确认）、恢复演示数据（确认后重置）、提成规则只读展示。

## 本地使用

直接用浏览器打开 `index.html` 即可，无需安装、无需联网（页面无任何外部依赖）。数据存在本机浏览器的 localStorage（key：`phone-store-v1`），换浏览器或清除浏览器数据会丢失，请在"设置"页导出备份。

发布到静态托管：把整个目录上传即可（纯静态，无构建步骤）。GitHub Pages：仓库设置里开启 Pages，选根目录。Altare：把目录作为静态站点上传。

## 演示数据

首次打开自动写入一套演示数据（也可在"设置"页恢复）：

- 8 款手机（iPhone 17 / 17 Pro、华为 Mate 80、小米 17、OPPO Find X9、vivo X300、荣耀 Magic 8、三星 S26）+ 4 个配件（钢化膜 / 手机壳 / 充电器 / 耳机），手机每台带 2–3 条在库串号；
- 供应商 3 家、店员 4 名（含店长）、会员 3 名、1 张待收货采购单、1 张待检修维修单、2 条演示国补记录。
